# Data Source

This project uses synthetic and benchmark-style contract examples for development and testing.

- Source family: CUAD-style contract clause examples.
- License: CC BY 4.0.
- Intended usage: educational and research-oriented evaluation within this repository.
- Retention: keep generated artifacts in local project folders only; avoid external publishing unless approved.

## Storage Rules

1. Store raw source documents in the project-controlled `data/` area.
2. Keep hashes and manifests for provenance tracking.
3. Do not commit secrets or personal data in fixtures.
4. Prefer synthetic or public non-sensitive content for demos and tests.
